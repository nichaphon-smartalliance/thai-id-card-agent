ตัวกลางระหว่าง “บัตร” กับ “เว็บไซต์”

เว็บเบราว์เซอร์อ่านบัตรประชาชนเองไม่ได้ — Thai ID Card Agent จึงทำหน้าที่เป็นสะพาน คอยอ่านข้อมูลจากชิปบนบัตรแล้วส่งต่อให้เว็บที่รองรับ คุณไม่ต้องเปิดโปรแกรมอะไรเอง แค่เปิดเครื่อง มันก็พร้อมทำงานแล้ว

อ่านบัตรอัตโนมัติ

เสียบบัตรเข้าเครื่องอ่าน ข้อมูลพร้อมให้เว็บดึงไปใช้ภายในไม่กี่วินาที พร้อมรูปถ่าย

ทำงานเบื้องหลัง

ติดตั้งเป็นบริการของ Windows เปิดเครื่องมาก็เริ่มเอง ไม่ต้องคอยเปิดหน้าต่างค้างไว้

เชื่อมกับเว็บได้ทันที

เว็บแอปต่าง ๆ เรียกใช้ผ่าน localhost:9001 ได้เลย ไม่ต้องตั้งค่าเพิ่ม

ดับเบิลคลิก

เปิดไฟล์ติดตั้ง

ดับเบิลคลิกที่ ThaiIDCardAgent-Setup.exe เมื่อ Windows ถามเรื่องสิทธิ์ (User Account Control) ให้กด “Yes”

แก้ปัญหาเบื้องต้น

เจอปัญหา? เริ่มจากตรงนี้

ปัญหาส่วนใหญ่แก้ได้เองในไม่กี่คลิก — คลิกที่หัวข้อเพื่อดูวิธีแก้

› เปิด /readers แล้วเห็นวงเล็บว่าง [ ]
ระบบยังไม่พบเครื่องอ่านบัตร ลองทำตามนี้ตามลำดับ:
1) ถอดแล้วเสียบสาย USB ของเครื่องอ่านใหม่   2) ตรวจว่าได้ติดตั้ง driver ของเครื่องอ่านแล้ว   3) เปิด services.msc ดูว่าบริการ Smart Card กำลังทำงาน (Running)
› กดอ่านบัตรแล้วขึ้นว่า “ไม่พบบัตร”
เสียบบัตรให้แน่นโดยให้ด้านชิปทองเข้าไปก่อน รอ 1–2 วินาทีแล้วลองใหม่ และเช็กว่าหน้าสัมผัสชิปบนบัตรไม่สกปรกหรือมีรอยขีดข่วน
› เว็บเชื่อมต่อ Agent ไม่ได้
ลองเปิด http://localhost:9001/readers ในเบราว์เซอร์โดยตรง ถ้าเปิดไม่ขึ้น แสดงว่าบริการอาจหยุดทำงาน ให้รีสตาร์ตเครื่องหนึ่งครั้ง (บริการจะเริ่มเองอัตโนมัติ) หรือเปิด services.msc → หา ThaiIDCardAgent → คลิกขวา → Start
› ชื่อภาษาไทยแสดงเป็นตัวอักษรประหลาด
ฝั่งเว็บต้องแสดงผลเป็นภาษาไทย (UTF-8) ตัว Agent ส่งข้อมูลภาษาไทยมาถูกต้องอยู่แล้ว หากยังเพี้ยน ให้แจ้งผู้ดูแลระบบเว็บที่คุณใช้งาน
› ต้องการให้ทำงานหลังเปลี่ยนเครื่องอ่าน
ถอด-เสียบเครื่องอ่านใหม่ได้เลย Agent จะตรวจจับให้อัตโนมัติ ไม่ต้องติดตั้งใหม่ หากใช้หลายเครื่องอ่านพร้อมกัน เว็บจะให้เลือกว่าจะอ่านจากเครื่องไหน

ข้อมูลของคุณปลอดภัย

Agent ทำงานเฉพาะในเครื่องของคุณ (localhost) เท่านั้น ไม่ได้เปิดให้เครื่องอื่นในเครือข่ายเข้าถึง และจะอ่านข้อมูลก็ต่อเมื่อมีบัตรเสียบอยู่จริงและมีเว็บร้องขอเท่านั้น — ไม่มีการเก็บหรือส่งข้อมูลออกไปไหนเอง
